# A股板块资金走势 V1.0

面向 A 股盘中观察的单页资金看板。直接打开 `index.html` 即可使用，无需安装依赖或启动后端服务。

## V1.0 新增功能

- 板块资金主图支持累计净额、5 分钟流速，以及全天、60 分、30 分、15 分、5 分、3 日、5 日、10 日视图。
- 3/5/10 日板块数据使用本地缓存、后台预热和请求去重，切换时优先立即展示缓存并在后台更新。
- 日线历史仅保留前一交易日及再往前 10 个交易日；当天数据继续使用盘中实时值。
- 主图增加上证指数、创业板指、科创 50 当日走势，可单击指数按钮独立显示或隐藏。
- “与指数共振”改为比较分钟曲线的方向一致率与正相关性，不再只看涨跌百分比。
- “与指数背离”增加背离度，综合盘中反向率与负相关性，并支持展开板块个股。
- 共振和背离个股按参照指数限定股票池：沪深主板为 60/00，创业板为 300/301，科创板为 688。
- 全市场 ETF 资金净额支持当日、3 日、5 日、10 日合计、资金广度、强弱首位和排行。
- ETF 模块提供分钟走势、关注列表、强弱锚点和全市场本地排序。
- 修复手机端展开个股时名称被遮挡的问题，并优化窄屏布局。
- 支持浅色/深色主题及离线快照保存。

## 使用方式

1. 使用现代浏览器打开 `index.html`。
2. 等待东方财富行情接口完成首次加载。
3. 点击时间范围、指数、板块或 ETF 标签查看对应数据。

## 数据说明

- 数据源为东方财富公开行情接口。
- 页面展示的是二级市场主力大单净买卖额，不等同于 ETF 申购赎回数据。
- 共振度、背离度和资金流仅用于结构观察，不构成投资建议。
